# THE SUNDAY WIRE

A one-page wire-service front page summing up the world news of Sunday
22 November 2026. Three verified leads run as full-width rows — the COP31
deal closing in at dawn, Russia's 400-drone and 110-missile barrage on
Ukraine, and Iran's strikes on US bases in Bahrain — above ten medium
stories, a dotted world map with numbered pins, 25 more stories, and a
DATE CHECK box that lists what was left out on purpose. 38 stories in all,
every one dated Sunday 22 November 2026, every one naming its outlet.

## Run

`main.py` (Python 3.13, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`. Run it twice and both runs write the same
bytes:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
